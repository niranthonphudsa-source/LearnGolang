Go module คือ Collection ของ package ที่เกี่ยวข้องที่เราจะใช้งานร่วมกับ Project


โดยการจัดการ module นั้น จะมี 2 flie ที่เป็น flie หลักคือ

    1. go.mod list dependency ทั้งหมดของ go ไว้
    2. go.sum คือไฟล์ที่เก็บเวอร์ชั่นลอเอาไว้(ใช้เช็คว่าเรา Load มาถูก version )

ตัวอย่างการใช้ Go module

    1. เริ่มต้น init Go Module ขึ้นมา

        go mod init github.com/name repository

    2.ดึงไลบารีไม่ใช้โดยใช้คำสั่ง 
        go get (repository)
        => go get github.com/google/uuid
